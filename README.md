# Gruppenarbeit Programming

Gemeinsames Repository unserer Gruppe für den Kurs Introduction to Programming (Nova SBE).

## Mitmachen

1. Einladung annehmen: https://github.com/Mou2110/gruppenarbeit-programming/invitations
2. Repository klonen:
   ```bash
   git clone https://github.com/Mou2110/gruppenarbeit-programming.git
   ```
3. Für jede Änderung einen eigenen Branch anlegen und einen Pull Request öffnen – nicht direkt auf `main` arbeiten.
